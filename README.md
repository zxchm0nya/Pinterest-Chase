# Pinterest-Chase
Pinterest Chase — LAN-игра для друзей. Хост создаёт лобби, игроки подключаются по сети или Radmin VPN и соревнуются, кто быстрее найдёт путь от стартовой темы до цели через Pinterest или Wikipedia. Есть друзья, приглашения, таймер, места, история матчей, звуки и сдача без победителя.
